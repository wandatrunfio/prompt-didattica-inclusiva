# Prompt per una didattica inclusiva

Raccolta interattiva di prompt per far creare a un assistente di intelligenza artificiale lezioni, Unità di Apprendimento, testi livellati e materiali personalizzati per la scuola dell'infanzia, la scuola primaria e la scuola secondaria di primo grado, con attenzione all'inclusione di tutti gli studenti.

- 47 prompt divisi in 17 aree (progettazione UdA, inclusione e valutazione, testi livellati, ortografia, scrittura, poesia e letteratura, storia, geografia, scienze, matematica, equazioni, geometria, arte, tecnologia, coding, metodo di studio)
- filtri per ordine di scuola, area e parola chiave
- pulsante "Copia prompt" su ogni riga
- 10 richieste di rilancio per adattare il materiale dopo la prima risposta

## Come pubblicare la pagina con GitHub Pages

1. Carica `index.html` e `logo.png` nella radice del repository.
2. Vai su **Settings → Pages**, scegli *Deploy from a branch*, branch `main`, cartella `/ (root)` e salva.
3. Dopo un minuto la pagina sarà online all'indirizzo `https://NOMEUTENTE.github.io/NOMEREPOSITORY/`.
